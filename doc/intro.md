# Documentation

Use this folder to grow project documentation alongside the codebase.
The default layout keeps content modular so teams can quickly expand it
for new projects.

## Structure

- `setup.md` — how run the software locally.
- `architecture_decisions/index.md` — architecture decisions protocols
- `architecture/index.md` — key design decisions, dependencies, and
  integration points.
- `operations/index.md` — deployment, monitoring
