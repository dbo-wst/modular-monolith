# 3. core protocol

Date: 2026-04-01

## Status

Accepted

## Context

The system needs a way to communicate with the external world. The protocol must provide a consistent foundation for data exchange while remaining flexible enough to evolve over time.

## Decision

Adopt a protocol that is uniform, adaptable and extensible
This protocol will define a common format for all data managed in trios.

## Consequences

All data managed in trios will follow a uniform structure. This improves consistency, makes integrations easier, and supports future changes and extensions.
